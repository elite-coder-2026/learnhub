Yeah I'll get it# LearnHub Feature Roadmap

## Must Have

- [x] User registration & login (student, instructor, admin roles) with JWT auth
- [x] Instructor: create/edit courses with modules and lessons
- [x] Student: browse and enroll in courses
- [x] Student: view lesson content and mark lessons complete (auto + manual)
- [x] Student: course progress tracking (% complete, per-lesson status)
- [x] Instructor: view list of students enrolled in a course
- [x] Assignment submission (student) and review/grading (instructor)
- [x] Admin: manage users (view, deactivate/soft-delete)
- [x] Admin: manage courses (view, remove)
- [x] Role-based access control enforced on every route

## Nice to Have

- [x] Course search and filtering (by category, instructor, level)
- [x] Student dashboard: in-progress vs completed courses
- [ ] Instructor analytics: enrollment counts, completion rates per course
- [ ] Course reviews/ratings from students
- [ ] Email notifications (enrollment confirmation, assignment graded)
- [ ] Certificates of completion (generated on 100% course progress)
- [ ] Admin platform-wide analytics dashboard (active users, top courses)
- [ ] Bulk lesson upload/reordering for instructors

## Bonus

- [ ] Fraud detection integration (flag suspicious enrollment/payment patterns via the Python microservice)
- [ ] Discussion forum / Q&A per lesson
- [ ] Wishlist / save-for-later courses
- [ ] Instructor payout/revenue tracking
- [ ] Multi-language course content support
- [ ] Offline lesson download (progressive web app)
