# Backend Dependencies

## Dependencies

- **express** — HTTP routing and middleware framework
- **pg** — PostgreSQL driver (node-postgres); raw SQL only, no ORM
- **cors** — Cross-Origin Resource Sharing middleware
- **jsonwebtoken** — JWT creation and verification for authentication

## Dev Dependencies

- **typescript** — strict-mode TypeScript compiler
- **@types/node** — Node.js type definitions
- **@types/express** — type definitions for Express
- **@types/cors** — type definitions for cors
- **@types/jsonwebtoken** — type definitions for jsonwebtoken
